知仓（ZhiVault）隐私政策

生效日期：2026年9月4日 | 版本：V1.0 | 适用应用：知仓 (ZhiVault)

知仓（ZhiVault，以下简称“我们”或“本应用”）高度重视用户的个人隐私与数据安全。本应用专为 HarmonyOS（鸿蒙）平台打造，旨在帮助用户通过自有 Git 仓库在不同设备间安全、可靠地同步本地 Markdown 知识库与个人笔记。

特别声明：本应用采用“本地优先（Local-First）”与“端到端自主掌控”的设计理念。我们不架设任何中转服务器收集或存储您的笔记内容，亦未集成任何第三方广告、埋点分析或用户画像 SDK。您的数据完全归您自己所有。

一、我们收集哪些信息

本应用不主动收集任何个人身份信息或设备隐私数据：

  • 无个人账号体系：使用本应用无需注册、登录或提供手机号、邮箱、姓名等个人身份信息。
  • 不收集笔记内容：您的文档、知识库目录结构、文件内容仅存放于您设备本地指定的沙箱/授权目录，以及您自主配置的 Git 远端仓库中。
  • 不收集使用行为：应用不记录您的点击、操作习惯、使用时长，无任何第三方追踪埋点。

二、应用权限调用与使用场景公示

为了实现核心的 Git 仓库同步及文件跨生命周期保存功能，本应用会在必要时向系统申请以下权限：

权限名称 权限类型 使用目的与场景
网络访问权限
(ohos.permission.INTERNET)		 系统基础权限 仅用于与用户主动配置的 Git 远端服务器（如 GitHub、Gitee、GitLab 或自建 Git 服务）进行安全的 clone、pull、push 网络通信。应用绝不会连接任何未经用户授权的第三方服务器。
文件持久化授权
(ohos.permission.FILE_ACCESS_PERSIST)		 受限权限 (ACL) 仅用于保持对用户在文件选择器（Picker）中主动授权的特定知识库文件夹的持久访问。确保在应用重启或后台服务恢复后，依然能够执行已配置的同步操作，免去频繁重复弹出系统选择框的干扰。本应用绝不会扫描或读取您设备中的其他未授权目录。

三、凭据与敏感数据存储

  • 访问令牌（Token）与凭据存储：您在添加 Git 远端时填写的个人访问令牌（Personal Access Token）或认证信息，通过 HarmonyOS 提供的底层安全加密能力存储在本地沙箱安全区域。
  • 绝不外传：此类认证凭据仅在与您指定的 Git 远端服务器发起认证握手时使用，绝不上传至任何其他第三方服务器。
  • 即时销毁：当您在应用内移除知识库或卸载本应用时，对应的本地数据库记录及加密凭据将一并从设备中彻底抹除。

四、第三方服务与 SDK 披露

本应用恪守极简与本地原则：

  • 无第三方商业 SDK：本应用未集成任何第三方统计监控、崩溃上报、广告推送或社交分享 SDK。
  • Git 托管服务商：您同步所使用的远端平台（如 GitHub、GitLab、Gitee、自建服务器等）为独立第三方实体，您在各平台托管代码/文档的数据保护受各平台自身的隐私政策约束。

五、未成年人信息保护

本应用为通用型文档管理与版本控制工具，不包含任何限制级内容或针对未成年人的定向推荐，亦不会主动收集未成年人的个人信息。

六、政策的变更与通知

如果未来因功能迭代或法律法规调整需更新本隐私政策，我们将在应用版本更新日志以及本网页中提前发布最新版本。继续使用本应用即表示您知悉并同意接受修订后的政策内容。
